# Запуск — лабораторная по теории чисел

Python-проект, зависимости описаны в `pyproject.toml`. Виртуальное окружение
в репозиторий не кладётся.

## Как запустить

```
python -m venv .venv
.venv/Scripts/activate
pip install -e .
```

В оригинале окружение было закоммичено целиком — больше полутора тысяч файлов
`site-packages`. Убрано: ставится из `pyproject.toml`.
