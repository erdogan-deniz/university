# Сборка — HumanDetections

Детектор людей на EmguCV с расчётом на GPU. Проект .NET Framework, Windows Forms.

## Зависимости не лежат в репозитории

В оригинале рядом с проектом лежали готовые библиотеки: `Emgu.CV*.dll`,
`cvextern_gpu.dll` и рантайм CUDA 4.2 (`cudart32_42_9.dll`, `cufft32_42_9.dll`,
`npp32_42_9.dll`) — около 146 МБ бинарников. Из репозитория они убраны: это чужие
сборки, а не код работы.

По версиям рантайма видно, что использовался **EmguCV 2.4.x** под CUDA 4.2.

## Как собрать

1. Поставить пакет EmguCV через NuGet:

   ```
   nuget install Emgu.CV.runtime.windows
   ```

2. В `FaceDetection.csproj` ссылки на сборки заданы через `HintPath` и указывают на
   файлы, которых больше нет. Пути нужно переназначить на папку, куда NuGet положил
   пакет.

⚠️ Актуальный EmguCV — 4.x, и его API отличается от 2.4: часть вызовов в коде
придётся поправить. Проект сохранён как работа того времени, а не как собираемый
из коробки пример.
