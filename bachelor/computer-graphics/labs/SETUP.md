# Сборка — лабораторные по компьютерной графике

Проекты на C++ с OpenGL, Visual Studio (`OpenGLrememberProj.vcxproj`).

## Зависимости не лежат в репозитории

Рядом с проектом в оригинале были распакованы `GL/`, `GLFW/`, `SOIL/` и `glm-master/`
плюс архивы `glew-2.1.0.zip`, `glm-master.zip`, `soil-master.zip` — это чужие
библиотеки, а не код работы. Список и источники — в [dependencies.txt](dependencies.txt).

## Как собрать

1. Скачать три библиотеки по ссылкам из `dependencies.txt`.
2. Распаковать их рядом с `.vcxproj`, в папки `GL/`, `GLFW/`, `SOIL/`, `glm/`.
3. Открыть проект в Visual Studio и собрать.

⚠️ Точные коммиты GLM и SOIL не зафиксированы — в оригинале лежали снимки `master`
без версии. Указана только версия GLEW, она была в имени архива.
