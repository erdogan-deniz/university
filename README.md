## Как устроен репозиторий

```
bachelor/<discipline>/
    lectures/        материалы курса
    seminars/
    labs/            мои работы
    coursework/
    works/  exam/  credit-test/  reports/
bachelor/internships/
thesis/
master/<discipline>/
master/internships/
```

Имена папок и файлов — английские (с 30.09.2026): дисциплина из таблицы выше лежит в папке
с её английским названием, например «Базы данных» — `bachelor/databases/`, «Электротехника» —
`bachelor/electrical-engineering/`. Дисциплина появляется в дереве, только если по ней
сохранились файлы; у остальных в колонке «Материалы» стоит «—». Из четырёх практик материалы
сохранились по двум.

## Зависимости

Чужие библиотеки и собранные бинарники в репозиторий не кладутся — ни `.dll`, ни
`packages/`, ни `node_modules/`, ни виртуальные окружения. У каждого проекта, которому
нужна сборка, рядом лежит `SETUP.md` с точными версиями и командами: `nuget restore`
для проектов .NET, `composer install` для Laravel, `pip install -e .` для Python,
ручная установка GLEW/GLM/SOIL для лабораторных по компьютерной графике.

## Лицензия

Материалы здесь трёх видов, и права на них разные — подробно в [LICENSE](LICENSE).

- **Мои работы** (`labs/`, `works/`, `coursework/`, `reports/`, `thesis/`, `master/`) —
  код под MIT, тексты и документы под CC BY 4.0. Переиспользуйте с указанием автора.
- **Материалы университета** (`lectures/`, `seminars/`, методички, задания в `exam/`
  и `credit-test/`) — работа преподавателей МГТУ «СТАНКИН», лицензия на них
  не распространяется. Выложены как часть учебного архива, чтобы было видно,
  по чему я учился. Автор материала может написать — уберу.
- **Стороннее ПО** внутри учебных проектов (каскады OpenCV, Emgu CV, скелет Laravel) —
  по своим лицензиям, указанным рядом с ними.
