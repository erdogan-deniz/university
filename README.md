## Как устроен репозиторий

```
Бакалавриат/<Дисциплина>/
    Лекции/          материалы курса
    Семинары/
    Лабораторные/    мои работы
    Курсовая/
    Работы/  Экзамен/  Зачёт/  Отчёты/
Бакалавриат/Практики/
ВКР/
Магистратура/<Дисциплина>/
```

Дисциплина появляется в дереве, только если по ней сохранились файлы; у остальных
в колонке «Материалы» стоит «—». Три папки названы короче официального имени, чтобы
пути влезали в ограничения Windows: «Всеобщая история», «История России»,
«Электротехника». Из четырёх практик материалы сохранились по двум.

## Зависимости

Чужие библиотеки и собранные бинарники в репозиторий не кладутся — ни `.dll`, ни
`packages/`, ни `node_modules/`, ни виртуальные окружения. У каждого проекта, которому
нужна сборка, рядом лежит `SETUP.md` с точными версиями и командами: `nuget restore`
для проектов .NET, `composer install` для Laravel, `pip install -e .` для Python,
ручная установка GLEW/GLM/SOIL для лабораторных по компьютерной графике.
